
# Nivo Étterem

A Nivo Étterem egy vizsgaremek keretében készülő, komplex éttermi informatikai rendszer, amelynek célja a vendégek kiszolgálásának és az étterem mindennapi működésének egyszerűsítése.

## A projekt részei

- **Éttermi weboldal:** az étterem és szolgáltatásainak bemutatása.
- **QR-kódos rendelési rendszer:** digitális étlap és asztalhoz kötött rendelésleadás.
- **Asztalfoglalás:** foglalások és szabad asztalok kezelése.
- **Adminisztrációs alkalmazás:** ételek, rendelések és az étterem adatainak kezelése.
